What’s an install, exactly?

Honest answer: we cannot fully define it yet, and the whole model inherits that. The working shape: a small database for the business, ETLs that port their data in (customers, jobs, bills, rates), and a few agents put on routine duty on top of it. The first five paid installs define the real unit; until then the install fee dial is a hypothesis band, not a price list.

The first agents on the roster

Fish for reviews and answer them. Reconcile the bills. Regenerate the rate sheet when costs move. Draft quotes with AI concept images the customer can react to. Each one is a playbook chapter; the installs will tell us which chapters every business needs and which are one‑offs.
